Desktop installers for The Proper Volume Karaoke Booth 0.8.0.

- Windows x64: setup installer and portable ZIP.
- Linux x64: Debian package and AppImage.
- macOS: separate Apple silicon and Intel DMG/ZIP packages.
- Generated Word specification, Night/Day mockups, build receipts and SHA256 checksums.

Source: 753e22150b75599dc334200015f9a44e3a2ee070. All packages and planning files use this same commit.

Development prerelease; 1.0.0 is the official release target. Windows/Linux packages are unsigned; macOS uses ad-hoc signing without Developer ID/notarization. Automated checks do not establish physical audio/display or installation compatibility. Back up your show before upgrading. External yt-dlp and FFmpeg are not bundled.

See the repository installation guide for setup and verification scope. GitHub also provides source archives below.
