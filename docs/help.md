# Karaoke Booth Documentation

Use these guides to set up Booth, run a show and help singers join. The desktop help includes these guides for offline use.

Start with the [Installation Guide](installation.md) for supported packages and CLI setup.

Choose **Help → About** to see the product name, running version and publisher. **Help → What's New** opens the latest release notes in your browser.

## Run a Show

- [Host Workspace](host-workspace.md) covers setup, the library, playlists, preferences, and the singer display.
- [Queue Management](queue-management.md) explains singer rotation, approvals, holds, and reordering.
- [Playback Controls](playback-controls.md) explains starting the show, seeking, and recovering stalled playback.
- [Keyboard Shortcuts](keyboard-shortcuts.md) lists the defaults and explains how to change them.

## Set Up Your Library

- [Import Jobs](import-jobs.md) covers video and folder imports, progress, and error reports.
- [CD+G and LRC Imports](cdg-import.md) covers paired lyrics and audio, ZIP imports, and lyric backdrops.
- [Filename Metadata Templates](metadata-templates.md) explains how Booth extracts titles and artists from paths.
- [Show Backups](show-database-safety.md) explains what to back up and how to restore a show.

## Invite Singers and Use the CLI

- [Singer Guide](singer-guide.md) explains how to join a room, request songs, and watch the singer screen.
- [Mobile Guide](mobile-app.md) covers Full Host and Piggyback modes on a phone or tablet.
- [Local API and CLI](local-control-api.md) explains CLI setup and available commands.
