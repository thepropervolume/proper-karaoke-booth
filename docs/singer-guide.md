# Singer guide for the rehearsal build

The host operates the app on a computer. They can enter a request for you, or may invite you to try the experimental local-network singer page. Internet access and account sign-in are not available.

## Join from the venue network

If the host has opened a local room, connect to the venue network and open the private invitation link they share with you. Enter your name and choose **Join the show**. The page lets you search loaded songs, request a song and check your request status. Use **Load more songs** to browse additional pages of the library. If you cannot find a song, enter its title and optional artist under **Can't find your song?** and send it to the host; this does not add a recording or a rotation entry.

Your invitation can be used by anyone who has it until it expires or the host revokes it, so do not share it without the host's permission. Your access is tied to the open page; if you close or reload it, ask the host for a new link. Closing the room revokes guest access. The local page requires the host's network name and certificate to be trusted by your device. This experimental flow has not yet been verified on physical iOS or Android devices; ask the host to enter your request if it does not work. Do not bypass a browser certificate warning.

## Request an available song

1. Tell the host your name and the song or artist you would like to sing.
2. The host searches the local library and double-clicks a song. They can choose your name or enter a new name in the request dialog.
   If the host is importing a library, newly imported songs appear as they finish; ask them to check again if your song has not appeared yet.
3. Requests are approved automatically by default. If the host has switched to manual approval, the request waits for their review before joining the queue.
4. The host starts the performance when it is your turn. Queue order depends on whether the host selected singer rotation or first requested, first played. If enabled, the singer display shows upcoming singers; the host may also set a gap between songs. The host starts the next song after the gap; it does not start automatically. The app checks the song file before starting; if it has moved or changed, the host may need to locate the original before your performance.

## Ask for a song that is missing

Tell the host the song title, your name and, if known, the artist. They can save it under **Can't Find a Song?** in the library. It appears in the host's **Missing-Song Requests** list, but saving it does not add the recording to the library or put you in the rotation. The host needs an available recording before it can be requested for playback.

Your singer name and request information are stored locally for the host's show. The host can create singer playlists and review performances completed or skipped since the history feature was added. Personal self-service, favorites and cross-device profiles are not yet available.
