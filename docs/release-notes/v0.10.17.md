# 0.10.17

- Filter the Song Library by source and choose which columns appear in the compact results. YouTube rows show the cleaned title and artist, plus channel, length and publication date when available.
- Open Preferences → Karaoke Services to manage source visibility. Connecting an account enables its source. KaraFun keeps a remembered sign-in when a failed request does not indicate that the session expired.
- Right-click a singer to rename them or a ready library track to **Play Song Now**. Confirmed missing files are dimmed and must be relinked before queueing. Booth retries temporary local verification failures before asking the host to act.
- Star songs in Booth to add them to **KJ Picks**. On mobile or the browser singer page, starring adds songs to a personal playlist on that device. Existing ratings are retained.
- Use a single custom bumper track, open the bundled Local API and CLI guide directly from Preferences, and find blacklist and ratings configuration under Library Settings.
