# Booth 0.10.18

- The mobile singer app opens with The Proper Volume homepage identity, followed by guest entry or Booth account sign-in.
- Rooms, Search, Queue, Account, Playlists, and Now Playing use the approved phone layout. Connected singers can follow the public queue and playback data from compatible desktop hosts.
- Booth accounts use email-first password sign-in, with optional emailed sign-in links and password recovery. Playlist collections remain on the device.

The iOS internal beta uses build 22. Android and iOS share the same release version.
