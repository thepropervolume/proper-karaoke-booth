# The Proper Volume Karaoke Booth 0.10.9

- Run `tpv-karaoke-booth --help` from a new terminal. Windows Setup registers the command in PATH for the install scope. Debian installs it under `/usr/bin`, and the macOS PKG uses `/usr/local/bin`.
- Open **Help → Documentation** for the bundled, offline guides.
- Choose Booth Default, System Sans, Serif, or Monospace from **View → Font** or **Preferences → Appearance**. The choice applies to the host, native singer display, and lyrics that Booth renders itself.
- Use **File** for video, folder, and paired-lyrics imports. **Edit** opens Preferences, **Playback** provides transport controls, and **Window** controls host and singer fullscreen separately. **F11** toggles the host window by default.
