# The Proper Volume Karaoke Booth 0.10.7

- Use **Hold until returned** in a singer’s **Actions** menu. Their requests stay queued and other singers can continue. The host returns the singer when they are ready.
- Export a singer playlist or KJ Picks, then preview and import exact recording matches on another Booth. The exported file contains song metadata and identities. Import media separately.
- Find a version ID for queue commands with `tpv-karaoke library`. Results are paged and reflect the saved library and active source settings.
- Booth verifies and saves the existing show database before upgrading to schema 8. Keep that pre-upgrade copy if you might need to roll back.

Includes the 0.10.6 backup restore, media review, LRC import, and mobile storage and photo review updates.
