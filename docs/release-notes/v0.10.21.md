# 0.10.21

- The library opens empty until you search or choose sources to browse. Choose several sources and Booth remembers them on restart. Local files appear as **Filesystem** under **Source**.
- Click a column heading to cycle through ascending, descending and the default order. Sort by original filename from **Sort**, or right-click the column headings to choose which fields to show.
- The library has one **Import** button for files and folders. Remove individual entries or a folder's entries from the index while keeping the source files. Relink missing media to the original or confirm a replacement when the bytes differ.
- New lyric-pair and ZIP imports remember their source folder and original filename. Older conversions can be removed individually. Back up your show before upgrading if you plan to return to an older release, since Booth upgrades the show database to schema 9.
- **DJ Code** uses the local container's `CATALOGNUMBER` tag when available, then the filename template or code stored at import. Online recordings use provider or creator prefixes with an available recording identifier.
- Preferences has eight searchable categories. **Zen** is the default automatic bumper, and the built-in alternatives are easier to distinguish.
- **Remote Sessions** explains missing, invalid or rejected device profiles. A host on Linux or macOS can install its private file from the app. Internet rooms still require a separately provisioned profile for each hosting computer.
