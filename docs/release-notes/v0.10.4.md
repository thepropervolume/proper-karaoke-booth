# The Proper Volume Karaoke Booth 0.10.4

- Protects older desktop show databases with a validated standalone pre-migration backup. A failed backup stops the upgrade. Media and settings are not included, and in-app restore remains unfinished.
- Shows approximate singer-queue waits during eligible automatic playback, based on current remaining time, configured gaps and four minutes per earlier ready song. Estimates are withheld when readiness or timing is uncertain.
- Restores the mobile Full Host's current request paused at its last saved playback position across restarts and mode changes. YouTube seeking is approximate and an abrupt termination may lose the most recent pending checkpoint.
- Copies private singer-screen links with the dedicated booth hostname when the relay provides it. Older relay configurations continue to use the queue hostname.
- Keeps saved KaraFun sign-ins through temporary validation failures and cancelled reconnects. **Retry Saved Sign-In** checks the existing session without a password prompt.

A desktop Chrome rehearsal verified local-video recovery after mode switching and reload. Physical show-hardware, installed-system upgrade, real YouTube resume and Android/iOS tests remain open.
