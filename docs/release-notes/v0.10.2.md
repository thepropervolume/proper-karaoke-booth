# The Proper Volume Karaoke Booth 0.10.2

- Downloads no longer require a preview sign-in. Stable links point to the latest available version of each downloadable artifact.
- The release server keeps the five newest download sets and preserves older release notes and release information.
- Desktop and mobile development builds are published together. The Android APK is a debug build, the Android App Bundle is unsigned, and the iOS ZIP is for the Simulator rather than an iPhone.
- Version 0.10.1 introduced host and singer applause, show points, duet scoring, and singer photo sharing. Hosts can turn applause and points on or off in preferences.

The applause sounds are generated by the app; audio output and levels should be checked on your show equipment. Mobile Full Host does not yet award the lifetime song novelty bonus when previous-show history is unavailable.
