# The Proper Volume Karaoke Booth 0.10.8

- Read title and artist tags when editing an imported local MP4. With FFprobe installed, choose which values to copy and save to the library. Booth reads the original file without modifying it.
- Navigate the desktop queue with the arrow keys and Home or End. On mobile, queue edits announce the new position or remaining count and recover keyboard focus.
- The Debian installer requires native ALSA and uses a space-free installation path for Chromium’s sandbox fallback. Its menu entry keeps the full product name.

This release includes restore and media recovery, LRC imports, mobile storage and photo review, singer holds, playlist transfer, and the expanded local CLI from 0.10.6 and 0.10.7.
