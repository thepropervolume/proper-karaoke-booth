# The Proper Volume Karaoke Booth 0.10.3

**Deployment update, 20 November 2026:** The updated queue relay, singer/mobile assets and private booth viewer are live and passed synthetic public checks. The bullets below retain their original release-time wording.

- Replaces synthesized applause with six supplied recordings, played in order with up to three overlapping clips; the longest plays for about 11 seconds.
- Adds individual search switches for local files, Karaoke Nerds, YouTube, KaraFun, Party Tyme, Sunfly and Stingray while preserving queued and playing songs. New unbranded Karaoke Nerds entries retain their source; older ambiguous entries cannot be reliably classified.
- Improves Party Tyme multiword searches with a bounded retry after an empty result and highlights Party Tyme rows in yellow.
- Adds an experimental, opt-in internet singer-screen share with a private per-share link and visual-only frames. The updated relay must be deployed before use.
- Searches the complete saved host library from singer rooms, with matching-result pagination and source/policy filtering; internet sessions require the updated relay.
- Moves singer availability into an actions menu and allows confirmed removal from the active show while preserving history, playlists and points. Active and queued performances must first be removed or reassigned.
- Adds a review-and-apply workflow for filename metadata with before/after previews and changed-since-preview protection; file tags are not changed.
- Changes song ratings to 1–10 stars; selecting a star saves immediately and reports failures.
- Adds a searchable singer-playlist list and an expandable playlist creation form.
- Adds an opt-in CLI PATH installer for supported Windows, Linux and macOS packages. AppImage automatic installation is not supported, and the Local API remains a separate opt-in.

The applause recordings and CLI installation still require listening and install/removal checks on the intended show and desktop systems. Provider catalog access and availability depend on the account and service.
