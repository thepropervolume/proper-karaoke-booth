# The Proper Volume Karaoke Booth 0.10.6

- Restore a validated backup from **File → Restore Show Backup…**. Booth saves a rollback copy and restarts silently.
- Use **Song Library → Review Missing Files** to find and relink moved local songs. Playback recovery preserves the singer’s turn and last saved position.
- Import same-name timed LRC and audio files with the selected lyric backdrop. FFmpeg with libass and FFprobe are required.
- Manage saved videos from **Storage** in mobile Full Host. Mobile hosts can review and approve a singer’s photo before it appears.
- Use the local CLI to view the queue and, with a separate opt-in, add, moderate or reorder requests.
- The shared Karaoke Nerds reader reuses its verified snapshot when the catalog revision is unchanged.

This is a development release. Mobile store enrollment, real-device checks, and paid provider approvals remain pending. [Release acceptance checklist](../release-acceptance.md)
