# KaraBooth 0.10.22

- Open the queue homepage to find nearby rooms or join with a custom room code. The guest app distinguishes an unavailable room from a network error and asks for your singer name.
- Email sign-in keeps the submit button visible. Sign in with your password if you already set one, or follow the email link to set a first password. Rooms uses updated artwork.
- Set a host handle and DJ or brand name on your first desktop launch. When a room is online, scan the QR on the idle singer screen or in the host sidebar. Click the sidebar code to copy the public link. Hide it or set a custom URL in Remote Queueing.
- Use the verified Stable or Nightly yt-dlp build in Preferences. Custom executable paths are supported. KaraBooth detects FFmpeg and FFprobe, and Debian packaging declares FFmpeg as an installation dependency.
- Export and import configuration, save and load a show session, and adjust persistent interface zoom. Configuration Files links to a local rotating diagnostic log.
- Run `karabooth-cli` on the desktop. Windows setup offers CLI PATH and local API choices for new installs, and the Finish page can launch KaraBooth. The installed app name and version have separate fields.
- **Upgrade Now** downloads and verifies an update before handing it to the installer. Windows setup and a writable AppImage can relaunch KaraBooth. macOS and Debian use their native install flow.
