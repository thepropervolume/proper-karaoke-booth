# Provider and content metadata research

Public-source review updated 2026-11-10. **Paid provider integration is a high priority**, including a host using an existing subscription where the provider and account terms permit it. No playable provider is integrated, no partner credentials have been verified for this app, and no existing subscription has been verified to work in this app. The descriptions below are provider claims, not a contract or proof that a given use, territory or platform is supported.

Karaoke Nerds subsequently granted access to its community metadata feed and asked that it be called about once per day, with results cached. One successful initial fetch returned 64,261 records and seeded a local SQLite prototype; the central service and desktop catalog connection are not deployed. The snapshot contains YouTube watch links but no video files or verified video publication dates. The `Created` field is not evidence of publication date. Brand-page slugs, rather than brand or track codes, determine cache directories; the feed brand value remains an internal join key. A metadata credential does not establish media-download rights. See [catalog groundwork](karaokenerds-catalog.md).

- **KaraFun:** [KaraFun OEM](https://business.karafun.com/oem) describes partner API access, catalog, playback and synchronization, and explicitly advertises existing KaraFun user login with access to user-linked subscriptions and entitlements. This is a partnership offering, not evidence that any specific existing personal or professional subscription can be used here. Ask about partner eligibility and pricing, supported Windows/macOS/Linux and Electron playback, linking existing subscriptions and plan types, public-event and venue rights, offline playback, and reporting. Its [business terms](https://business.karafun.com/terms) restrict downloads and resale without authorization.
- **Party Tyme:** [Party Tyme Karaoke Pro](https://www.partytymeplayer.com/partytyme/site/?page_id=2345) advertises an API for player vendors, names third-party PC applications, and describes its Pro service as licensed for professional venues and events. Ask about partner eligibility, API documentation and test access, integrating an existing Pro account, commercial terms, supported platforms, territory and offline rules. Its public listing of third-party apps does not authorize this app.
- **Sunfly:** [Sunfly's API page](https://api.sunflykaraoke.com/) describes encrypted delivery, per-venue or per-customer subscriptions, play reporting, and a Node/Electron SDK available on request. It advertises a 30-day API and content trial, subject to account setup. Ask about trial eligibility, pricing, OS and SDK support, hosting rights and territories, offline and reporting requirements, and whether any existing subscription can be linked. A provider flag is not a verified clean rating when absent.
- **Stingray:** [Stingray's getting-started guide](https://karaoke-api-doc.stingray.com/docs/introduction/getting-started/) describes a REST catalog/playback API and obtaining credentials from support. Its [design guidelines](https://karaoke-api-doc.stingray.com/docs/introduction/design-guidelines/) describe delivery restrictions. Ask about partner eligibility and pricing, existing-account compatibility, approved desktop playback, public-event rights and territories, reporting and caching.

## High-priority discovery and implementation

1. Prepare a short partnership inquiry and technical questionnaire for each provider. Ask specifically whether a host can connect an existing paid account, which subscription types and territories qualify, and what commercial terms and public-performance rights apply.
2. Obtain provider-approved documentation, test credentials and SDK access where offered. Verify authentication, search, exact-version identity, playback, queue integration, offline behavior, expiration, disconnection and reporting on supported platforms; do not assume the consumer subscription alone grants third-party access.
3. Design a provider adapter with separate provider entitlements and app subscriptions, protected credential handling, explicit track identity, availability and errors, and policy checks before discovery, queueing and playback. Keep local playback usable when a provider is unavailable. Prototype against provider-approved tools or fixtures before representing an integration as supported.
4. Compare the providers on catalog, host workflow, video and audio capabilities, pricing, territory, platform support and show continuity, and update the specification, host guidance and test plan once answers are verified.

## Other content research

- [LyricFind LyricIQ](https://www.lyricfind.com/products/lyriciq) describes lyric content filtering and classification. Confirm availability, category coverage, version matching, cost and permitted use of returned analysis. [LyricFind's description of its Tuned Global partnership](https://emu-glockenspiel-tn75.squarespace.com/press/jan23-tuned-global-and-lyricfind-announce-partnership) reports age-appropriateness filtering.
- Musixmatch is a candidate for licensed lyrics and metadata. The public material reviewed did not establish rights to obtain lyrics for independent automated classification, matching accuracy for karaoke versions, or API pricing; request terms before choosing it.

Store any future advisory or separately labeled automated assessment on the exact recording/version with source, confidence, coverage, time and provenance. An MP4 or CDG display is not proof of accessible, licensed lyric text. Host decisions, provider advisories and automated assessments must remain distinguishable.
