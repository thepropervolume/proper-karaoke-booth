# Zen

`Zen.ogg` is the default automatic bumper recording supplied by the project owner. It is included byte for byte as stereo 44.1 kHz Vorbis, with a duration of 140 seconds.

SHA-256 `e64206946fceefe2f4a640ae7afe7911041f45fcd01b11b60275180cf1006250`.

The recording is distributed as an application asset. The MPL 2.0 grant for the Booth code does not grant rights to the recording.
